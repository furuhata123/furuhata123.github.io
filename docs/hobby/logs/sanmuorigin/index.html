(2026-05)原本並不看好，因爲個人不喜歡原創主角塞進歷史游戲，但玩過后完全改觀，可以説是近幾年最佳三國無雙。新做的角色設計捨棄了原有的喜劇感（許褚...）劇情上顯得更加嚴肅，其中最成功的莫過於對張角的改編，游玩過程中幾度聯想到Jesus Christ？我對農民起義態度是矛盾的，游玩前幾代過程中似乎只有劉備會象徵性說幾句“他們也是受苦之人啊”，然後接著殺殺殺，而本代添加了更多黃巾軍劇情，配合NS2的機能，表現力十足。（NS1上的三國無雙7甚至顯得有點像low-poly時代...）曾經我以爲到赤壁便結束是一大敗筆（還沒玩夠）現在想想起源這樣的表現力，如果玩到後期劇情，故人一一逝去的悲涼感勢必比7代更加衝擊，也許停在此處也不錯吧
